### Support {#support}

Klaar is free. If it helps you, you can [buy me a coffee](https://www.buymeacoffee.com/iamfran). Found a bug or something that looks off in your theme? Please [open an issue](https://github.com/i-am-fran/obsidian-klaar/issues).

### Development {#development}

```bash
npm install
npm run dev     # watch build to main.js
npm run build   # type-check and production build
npm test        # vitest
npm run lint    # eslint
```

Changes are listed in the [changelog](https://github.com/i-am-fran/obsidian-klaar/blob/main/CHANGELOG.md). Klaar is [MIT licensed](https://github.com/i-am-fran/obsidian-klaar/blob/main/LICENSE).
