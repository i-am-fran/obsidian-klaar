### Settings {#settings}

| Setting | Default |
| --- | --- |
| Journal notes folder | `Daily` |
| Add completed date | on |
| Mark in progress with `[/]` | on |
| Mark next with `[>]` | on |
| Mark someday with `[<]` | on |
| Schedule labels | Friendly (`Fri 23 Oct`) |
| Completed date | Small and muted |
| Tags | `#p1`, `#p2`, `#p3`, `#bugs` |
| Period types | day, week, month, year (quarter off) |

### Support {#support}

Klaar is free. If it helps you, you can [buy me a coffee](https://www.buymeacoffee.com/iamfran).

### Development {#development}

```bash
npm install
npm run dev     # watch build to main.js
npm run build   # type-check and production build
npm test        # vitest
npm run lint    # eslint
```

Changes are listed in the [changelog](https://github.com/i-am-fran/obsidian-klaar/blob/main/CHANGELOG.md). Klaar is MIT licensed.
