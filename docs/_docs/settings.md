### Klaar settings {#klaar-settings}

Under Settings → Klaar:

| Setting | Default |
| --- | --- |
| Journal notes folder | `Daily` |
| Add completed date | on |
| Mark in progress with [/] | on |
| Mark next with [>] | on |
| Mark someday with [<] | on |
| Schedule labels | Friendly (Fri 23 Oct) |
| Completed date | Small and muted |
| Tags | `#p1`, `#p2`, `#p3`, `#bugs` |
| Period types | Daily, Weekly, Monthly, Yearly on; Quarterly off |

### Style Settings {#style-settings}

With the [Style Settings](https://github.com/mgmeyers/obsidian-style-settings) plugin installed, a Klaar section lets you change:

- **Pill tint**: how strongly a tag's colour fills its pill.
- **Text colour strength**: how much of the tag's colour goes into its text.
- **Pill corner radius** and **Tag font weight**.
- **Overdue date** and **Current date**: the date chip colours, for light and dark themes.

### Themes {#themes}

Klaar works with the default Obsidian theme and with Minimal, in light and dark mode. More themes will be tested over time. If something looks off in yours, please [open an issue](https://github.com/i-am-fran/obsidian-klaar/issues). With reduced motion turned on, nothing slides or fades.
